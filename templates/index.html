How The Suggestion Logic Works

1. Prefix Auto-Completion

Typing h scans the prefix Trie for common English words like hi, hello, how, have.

2. Trigram Next-Word LM

Typing hello my [space] triggers Markov chain P(w₃ | w₁, w₂) which predicts name with >69% and my name predicts is with >98%!

3. Bayesian Autocorrect

Typing helo detects a typo and generates edit-distance 1 candidates, recommending hello with 75% confidence.

4. Q-Gram Jaccard Metric

Computes character 2-gram overlap: |Q(A) ∩ Q(B)| / |Q(A) ∪ Q(B)| accelerated via inverted indexing in <3ms.
